# BirdEye Gujarat 🐦

AI-based bird species identification system using Flask and TensorFlow.

## 📌 Features

- Bird species identification using CNN
- Upload bird image for prediction
- Species details from dataset
- Habitat information
- Conservation status
- Rare/endangered bird detection
- MongoDB integration
- Responsive frontend UI

---

## 🛠 Technologies Used

- Python
- Flask
- TensorFlow
- CNN
- HTML/CSS/JavaScript
- MongoDB

## 🚀 Installation

### 1. Clone Repository

```bash
git clone https://github.com/thakkarpankti1312-netizen/BirdEye_Gujarat.git
```

### 2. Move to Folder

```bash
cd BirdEye_Gujarat
```

### 3. Install Requirements

```bash
pip install -r requirements.txt
```

### 4. Run Flask App

```bash
python app.py
```
